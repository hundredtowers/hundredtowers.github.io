# hundredtowers.github.io

The Hundred Towers site, served by GitHub Pages from `main` (root).

- `index.html`: publisher page
- `pagemile/`: Pagemile's page and privacy policy (`privacy.html`, `privacy-it.html`)
- `app-ads.txt`: the AdMob publisher line (pub-9218917190448360); `robots.txt` lets crawlers read it while the rest stays hidden

Contact address: hundredtowers.apps@gmail.com (a separate Gmail account for Hundred Towers).
The privacy policy must match the app's in-app privacy text (`legalPrivacyBody` in the Pagemile repo).
